# DataGEMS Query Recommender Api

This is the documentation site for the DataGEMS Query Recommender Api. The service is part of the wider [DataGEMS](https://datagems.eu/) platform. This is part of the overall [platform documentation](https://datagems-eosc.github.io/).

The Query Recommender Api suggests what a user might want to ask next. Given the natural language query the user has just submitted, it returns up to 3 short follow-up queries, personalised with the user's interest keywords as maintained by the [User Profiler](https://github.com/datagems-eosc/user-profiler) service. The suggestions are generated by a Large Language Model (LLM) served by the DataGEMS LLM endpoint.

A typical exchange looks like this:

```http
POST /api/v1/recommend-next-queries
Authorization: Bearer <token>
Content-Type: application/json

{
  "current_query": "What is there to do in Verona tonight?",
  "context": { "user_id": "user1" }
}
```

```json
{
  "next_queries": [
    "Concerts in Verona this weekend",
    "Opera at the Arena di Verona",
    "Late night restaurants in Verona"
  ]
}
```
